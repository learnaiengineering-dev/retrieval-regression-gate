# Changelog

All notable changes are listed here. This project follows semantic versioning.

## 0.1.0

- First release: `retrieval-gate` CLI, `compare()` API, JSON, text and Markdown reports,
  GitHub composite action, and example workflow.
- Embeddable `<retrieval-gate>` web component (`docs/retrieval-gate-widget.js`), an iframe-ready
  `docs/embed.html`, and a docs page with a live demo.
- Golden-file tests keep the Python package and the widget in agreement.
